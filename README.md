# Alternativa D — Carpas

Proyecto de Fundamentos de Programación, Universidad del Magdalena.

Integrantes: Álvaro Miguel Barco Juris y Beatriz Elena Andrews de la Hoz.

## Requisitos
Python 3.9 o superior. No requiere instalar paquetes externos.

## Ejecutar
```bash
python user_interface.py
```

## Ejecutar pruebas
```bash
python -m unittest -v
```

## Archivos
- `business_logic.py`: lógica y reglas del negocio.
- `user_interface.py`: menú de consola.
- `test_business_logic.py`: pruebas automáticas.
- `playas_ejemplo.csv` y `alquileres_ejemplo.csv`: datos de demostración.
- `docs/`: análisis, diseño, verificación, IA y video.

## Carga de datos
En la opción 6, introducir las rutas de `playas_ejemplo.csv` y `alquileres_ejemplo.csv`. Si se ejecuta desde la carpeta del proyecto, basta con escribir esos nombres.

## Advertencia académica
Este material es una base de trabajo. El estudiante debe ejecutar y comprender el programa, completar las evidencias reales, adaptar los documentos a las actividades realizadas y confirmar cualquier interpretación con el docente.
